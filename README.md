# JianZhou Xiao

### Robotics · Visuo-Tactile Learning · Efficient Machine Learning

I explore how tactile sensing, simulation, and data-efficient learning can support more capable and reliable intelligent systems.

## Areas I’m exploring

- Visuo-tactile robot manipulation and sim-to-real evaluation
- Data-efficient learning and sample allocation
- Robust and reproducible machine learning experiments

## Featured work

### Sample Budget Lab

An interactive, self-contained demo for exploring how a fixed sample budget can be split across training, validation, and testing. It uses simple illustrative arithmetic; it does not report results from a real dataset or model benchmark.

[Open the interactive lab](https://xiao2007-cosimo.github.io/XIAO2007-COSIMO/) · [View the source](https://github.com/XIAO2007-COSIMO/XIAO2007-COSIMO/blob/main/index.html)

### ZBS-P01 · 桩锁智能联控仿真

An interactive browser simulation for exploring parking access, occupancy, and charging-space operating rules. The repository includes the original Python prototype and an HSV plate-color threshold demo. Scenarios use generated inputs and do not connect to real equipment.

[Open the live simulation](https://xiao2007-cosimo.github.io/XIAO2007-COSIMO/projects/zbs-pile-lock-control/) · [View the project source](https://github.com/XIAO2007-COSIMO/XIAO2007-COSIMO/tree/main/projects/zbs-pile-lock-control)
